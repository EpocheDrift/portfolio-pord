# Project Asset Folders

Store approved production media by project slug.

```text
site/src/assets/projects/{project-slug}/
```

Current folders:

- `ccs/`
- `energy-sense/`
- `pour-decisions/`
- `chaos-interface/`

Suggested filename pattern:

```text
hero-01.webp
plate-01.webp
process-01.webp
diagram-01.svg
reference-01.webp
```

Before final deployment, prefer optimized image formats and update `site/src/data/projects.ts` with alt text and captions.
